Policy Sandbox

Experimentation sandbox — explores policy sensitivity via repeated simulation, does not affect the live agent's actual configuration.

Adjust the policy knobs, then run the simulation many times to see how recovery, escalation, and amount recovered respond — each reported as a mean with a 95% confidence interval. This is an analysis tool: runs happen in isolated in-memory databases and skip the LLM for speed (narration is template-based and never affects outcomes). The live agent's real retry cap, weights, and salary-window behavior are unchanged.

Chaos Suite

Adversarial test suite — deliberately attacks the system with malformed, malicious, and edge-case inputs. Runs against isolated in-memory databases; never touches the live demo data.

Seven adversarial scenarios — replayed webhooks, negative/zero amounts, duplicate customer IDs, clock-skew timestamps, malformed LLM responses, webhook-signature edge cases, and extreme volume. Each runs in its own fresh, isolated database. This is a diagnostic tool: it proves the system's defenses hold up under abuse and does not change any agent, scoring, or compliance behavior.

Run the suite to attack the system with seven adversarial scenarios and see a PASS/FAIL report for each.
